# TinyUSB

This directory contains the upstream TinyUSB `src` tree from release 0.21.0:

- repository: https://github.com/hathach/tinyusb
- tag: `0.21.0`
- commit: `dae3f9a366bfcddbf9dcf1b48d7500286a849539`
- license: MIT; see `LICENSE`

The complete source tree is retained so that device classes and MCU ports can
be enabled independently without copying partial upstream implementations.
MIOS32-specific configuration and adapters belong outside this directory.
